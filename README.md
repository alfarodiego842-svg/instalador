# 🚀 PSeInt - Guía Rápida de Instalación y Uso 💻

¡Bienvenido/a al repositorio! 👋 Aquí encontrarás el instalador oficial y una guía paso a paso para instalar y comenzar a programar en **PSeInt** de forma sencilla.

---

## 📌 ¿Qué es PSeInt?

**PSeInt** (PSeudo Intérprete) es una herramienta diseñada para estudiantes que están dando sus primeros pasos en la programación. Te permite aprender lógica de programación mediante **pseudocódigo** en español.

✨ **Características principales:**
* 🧠 Sintaxis simple en español.
* 📊 Generación automática de diagramas de flujo.
* 🛠️ Detección de errores en tiempo real.
* ⚡ Ejecución paso a paso para depurar tu código.

---

## 🛠️ Requisitos del Sistema

| Sistema Operativo | Versión Mínima |
| :--- | :--- |
| 🪟 **Windows** | Windows 7 / 8 / 10 / 11 |
| 🐧 **Linux** | Distribuciones de 32 y 64 bits |
| 🍎 **macOS** | macOS 10.7 o superior |

---

## 📥 Paso 1: Descargar e Instalar

1. **Obtener el instalador:**
   * Dirígete a la carpeta `/instalador` de este repositorio o descárgalo directamente desde el repositorio oficial.
2. **Ejecutar el instalador:**
   * Haz doble clic en el archivo ejecutable (`.exe` en Windows o `.dmg` en macOS).
3. **Completar el asistente:**
   * Acepta los términos de licencia y presiona **Siguiente** ➡️ **Instalar** ➡️ **Finalizar**.

> 💡 **Nota:** Si usas Linux, otorga permisos de ejecución al archivo con `chmod +x` antes de ejecutarlo.

---

## 🎯 Paso 2: Configuración Inicial del Perfil

Al abrir PSeInt por primera vez, verás la ventana de selección de perfil:

1. Selecciona la opción **"Opciones Precargadas"**.
2. Busca la institución educativa donde estudias o elige el perfil **Estricto** / **Flexible** según tus preferencias.
3. Haz clic en **Aceptar**.

---

## 🏁 Paso 3: Tu Primer Programa ("Hola Mundo")

Abre PSeInt y escribe el siguiente código en el editor:

```pseint
Algoritmo HolaMundo
    Escribir "¡Hola, mundo! Bienvenido a PSeInt 🚀"
FinAlgoritmo

```

### ⏩ Ejecutar el código:

* Presiona la tecla **F9** o haz clic en el botón verde de **Ejecutar** (▶️) en la barra de herramientas superior.
* Verás la consola emergente con el resultado.

---

## 📊 Dibujar Diagramas de Flujo

PSeInt convierte tu pseudocódigo en un diagrama visual de forma automática:

1. Escribe tu algoritmo en el editor.
2. Haz clic en el icono de **Dibujar Diagrama de Flujo** 📉 en la barra superior (o presiona `F7`).
3. ¡Listo! Puedes exportar el diagrama como imagen para tus trabajos académicos.
